## 这一版做了什么

参考你发的 **cactusdigitale.com**（法国 OB Studio 作品，2026-03 CSSLight 当日精选）——它的核心是：
观众站在一个**空间立方体内部**，图片和影片在四面墙上不断重新排布，形成不停流动的作品流；点进去还能在"超星座视图 ↔ 超特写"之间切换尺度。

我把它做成了**你的版本**：

| 参考站的做法 | 本站实现 |
|---|---|
| 空间立方体、作品贴在墙上 | 六面墙 = 六个项目位，Three.js 手写，无第三方库 |
| 作品在墙上持续重排 | 每 6.5 秒四面墙的贴图轮换一圈（`rearrange`） |
| 星座视图 ↔ 超特写 | 点墙面＝飞贴到该面墙；双击 / 按钮 / 滚轮外滚＝退回立体视图 |
| 白底编辑感 + 大留白 | 首页为白底编辑风；立方体内部为暗场，让作品浮起来 |

## 岩头村三维场地（village/）怎么来的

**数据源**：`2008-05 实测 1:500 地形图`（岩头村 / 研究范围）→ 抽取结果 `site_full.json`

| 数据 | 用量 | 处理方式 |
|---|---|---|
| 实测标高散点 | **175 个**（42.45–49.79 m） | IDW 反距离加权插值 → 121×121 高度场（2.5 m 网格），垂直夸张 4 倍 |
| 建筑轮廓 | **167 处**（红线内 30 处） | 按测绘材质层数（混3/砖2/简1）给真实层高（3.1 m/层）拉伸成体量 |
| 等高线 | 0.5 m 一条，整米加粗 | 前端 marching squares 实时计算 |
| 水系 / 道路 | 49 / 85 条 | 沿地形铺成带状（水系蓝、道路灰） |
| 研究范围红线 | 58 顶点 5873.1 ㎡ | 虚线框 + 广场半透明面（3424.9 ㎡） |
| 兴趣点 | 5 处 | 老戏台 / 中央广场 / 台仓 / 古井 / 巷口，点开有做法与论文依据 |

**操作**：拖动旋转 · 滚轮推拉 · **双击回全景** · 点兴趣点弹出说明并飞过去 · 左侧四种视角预设 · 右侧六个图层开关（等高线 / 建筑 / 水系道路 / 兴趣点 / 红线 / 自动环绕）

**视觉（第四版升级 · 治"玩具感"）**：
- **坡屋顶**：167 处建筑按轮廓长边生成双坡瓦屋顶（带 0.5 m 出檐、屋脊、瓦垄贴图），屋面颜色按实测材质变化——这是"模型感"最大的来源；
- **门窗**：面积 ≥110 ㎡ 的房子长边排窗（黄昏约 1/4 亮着暖光），南向加门；
- **树**：227 棵，沿道路两侧、沿水系、场地外围成片布置（树冠用低模多面体 + 4 种绿色变化），不再是孤零零的锥体；
- **地表贴图**：程序化草地/土斑噪声叠加在顶点色上，去掉大色块的塑料感；
- **水面**：低粗糙 + 金属感的湿面材质，随时间轻微闪动；
- **卫星影像底图**（腾讯位置服务静态图）：近景 538 m（0.526 m/像素）+ 远景 2153 m（2.102 m/像素）两层，径向渐隐接进雾里 —— **村子周边从此是真实的地形与村庄肌理**；
- 建筑红线标注改为**檐口描红**（比整个刷红更清楚也更像设计图）；
- 阴影相机收紧到 ±190 m，影子更利落。
